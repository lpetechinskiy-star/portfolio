# Портфолио leompi

Сайт-портфолио: разработка сайтов. Чистый HTML, CSS и JS, без сборки.

## Структура

- `index.html` — сам сайт портфолио
- `works/` — живые версии работ (открываются по кнопке «Открыть сайт»)
- `assets/shots/` — скриншоты работ: `*-cover.jpg` (первый экран), `*-page.jpg` (страница целиком, листается при наведении), `*-mobile.jpg` (версия для телефона)

## Как опубликовать на GitHub Pages

1. Откройте репозиторий на GitHub → **Settings** → **Pages**.
2. В **Source** выберите **Deploy from a branch**.
3. Выберите ветку с сайтом и папку `/ (root)`, нажмите **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу `https://lpetechinskiy-star.github.io/portfolio/`.

## Как добавить новую работу

1. Положите HTML-файл работы в `works/`.
2. Добавьте три скриншота в `assets/shots/` с теми же именами, что у остальных.
3. Скопируйте в `index.html` любой блок `<article class="work">` и поменяйте тексты, ссылки, картинки и цвет `data-c`.
